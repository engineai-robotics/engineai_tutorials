# pm01_navigation_sim

简体中文 | [English](README.en.md)

仿真平台适配。转换仿真步行命令、提供关节链动态 TF 与 Gazebo GUI 生命周期。

/cmd_vel → /pm01/walking_cmd_vel；LIO 与关节 TF → /odom。

准备期间，仿真插件保持初始姿态，物理时钟继续推进以激活控制器。初始姿态发布器等待控制器激活并按仿真时间完成保持，退出后才启动步行策略，避免两者同时写入关节目标。启动辅助节点等待步行策略服务就绪，完整站立重置成功后释放物理保持，确认新 IMU 数据连续站稳两个仿真秒，再由 bringup 启动 LIO；准备失败会终止启动。

本包不依赖真机运控消息。默认场景、步态配置与启动组合仍归 bringup；仿真导航不用 Gazebo 真值。
