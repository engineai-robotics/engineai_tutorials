# pm01_navigation_client

[简体中文](README.md) | English

Application interfaces and diagnostics. Provides Navigator, task lifecycle management, CLI commands, the simulation keyboard, and optional diagnostic recording through standard ROS interfaces.

Provides pm01_nav, pm01_sim_keyboard, pm01_clock_check, pm01_nav_debug, and from pm01_navigation_client import Navigator.

Choose a [Python client example](examples/README.en.md) for your task. Runtime implements the clock check. Diagnostic recording only collects data.
